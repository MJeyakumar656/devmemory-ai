📖 How to Use DevMemory AI

DevMemory AI is a coding teammate that saves useful project knowledge and chat exchanges in graph memory, so you can ask about them later.

Getting Started

1
Choose a Memory Space for the project or topic you are working on. Spaces keep their memories and conversations separate.
2
Ask or tell the AI in 💬 AI Chat. Ask about a saved fix or decision, or describe a new fix in natural language to save it.
3
Continue or start a conversation with the conversation list. Exchanges are saved to the active space and linked in its graph.
4
Review the graph and evidence to see which saved issues, fixes, decisions, or conversations support an answer.
5
Inspect agent activity to follow retrieval, reasoning, and any investigator-to-fixer handoff.

Chat Persistence

Each conversation is stored in the active space's graph memory. Use ＋ New for a separate chat or select an earlier conversation to continue it. The AI can use relevant saved exchanges from that space for follow-up context. The protected default space cannot be reset or deleted.

Keyboard Shortcut

Press Enter in the chat input to send a message. Use Shift+Enter for a new line.

👥 About DevMemory AI

DevMemory AI is a persistent graph-memory teammate built for the FalkorDB Hackathon — Track 2: Persistent Graph Teammate. It helps developers carry useful project context from one conversation to the next.

How It Works

  • 🧠 Graph memory — Connects projects, issues, fixes, decisions, sessions, tasks, and saved chat exchanges.
  • 🤖 Memory and task agents — Extract useful facts, retrieve relevant memories, and answer with supporting evidence.
  • 🔗 Agent coordination — Tracks investigation and fix workflows, including their handoffs and task state.
  • 🌐 Memory Spaces — Keep each project's graph and conversations isolated. The default space is protected from reset and deletion.

Core Cycle

Receive → Retrieve → Reason → Respond → Remember

Tech Stack

  • 🗄️ FalkorDB — Graph database, with local JSON fallback when unavailable
  • 🐍 Python / FastAPI — Backend agents and REST API
  • 🎨 HTML + D3.js — Interactive graph visualization
  • 📦 Pydantic — Structured agent schemas

Built for

Developers who want project knowledge to remain connected and inspectable, with answers grounded in retrieved memory rather than an untraceable chat history.

🤝 Help & Support

Use these checks to troubleshoot chat, memory, and graph behavior.

Common Issues

  • No matching memory — Check the selected space and project, then try distinctive words from the issue or decision. Save the knowledge first if it is not in the graph yet.
  • A new space has 0 nodes — New spaces start empty. Save a memory or chat in that space; existing spaces are not copied into it.
  • A conversation is missing — Select the space where it was created. Conversation lists and graph memories are isolated by space.
  • Backend is not responding — Start the app from the project folder with python main.py, then reload the page.
  • FalkorDB is unavailable — The app can use its local JSON fallback. To run FalkorDB locally, start it with docker run -p 6379:6379 falkordb/falkordb and restart the app.

Quick Tips

  • Use ＋ New to keep topics in separate conversations; selecting an earlier chat continues it.
  • State facts clearly, for example, "We resolved the login timeout by increasing the connection pool." The AI can save recognized fixes and decisions to graph memory.
  • Open Answer Evidence to inspect the memories and graph relationships supporting an answer.
  • Open Agent Activity to inspect retrieval steps, workflow status, and handoffs.
  • The default space is protected; create a separate space for data you may want to remove later.
